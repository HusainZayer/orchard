New tvOS 27.2 build for the updated Apple TV 4K

Apple released tvOS 27.2 build 24K154 only for the new fourth-generation Apple TV 4K, which launches 13 November at $299. Existing models stay on build 24K122. Apple hasn’t published release notes; one report says the build turns on Siri AI for the new box.
